
- Project Name

* Food Delivery Platform


- Purpose

Allow customers to order food from restaurants, restaurants to manage orders, drivers to deliver them, and administrators to manage the platform.

- Actors
* Customer
* Driver
* Admin
* Restaurant

- Goals
* Fast
* Scalable
* Microservice Architecture
* gRPC
* Docker
* Production Ready
* Event Driven

## Technical Goals

- Build a production-style backend using Go.
- Learn Microservice Architecture.
- Learn gRPC communication.
- Learn asynchronous communication with events.
- Learn Docker and Docker Compose.
- Learn distributed systems.
- Learn scalability patterns.
- Learn production deployment practices.

- Non-Goals
* No AI recommendations
* No coupons
* No multi-language
* No subscriptions
* No multiple currencies
* No restaurant analytics
